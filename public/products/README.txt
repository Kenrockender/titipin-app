TITIPIN — PRODUCT PHOTOS
========================

Drop your real product photos in THIS folder (public/products/).

NAMING RULE — the file name must match the product id, extension .jpg:

  <product-id>.jpg

The photo replaces the placeholder automatically. If a file is missing,
the app shows the Titipin placeholder (no broken image).

Recommended: square images, at least 640x640px, JPG or PNG (use .jpg name).
